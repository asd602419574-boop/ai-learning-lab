03｜神经网络怎么学：从双参数更新到反向传播

学习目标：解释损失、偏导和参数更新；手算权重与偏置的同步更新；沿计算图求一个隐藏神经元的梯度；核对小批量矩阵的形状；区分训练结果与泛化能力。

阅读分层：初学者先读第1—3节，亲手修改实验并理解误差如何改变参数。第4—6节是可选数学深入，不是学习可靠使用AI的前置门槛。需要的符号：Σ是求和，∂表示只改变一个变量时的变化率，T表示转置，⊙表示对应位置相乘。

1. 先把模型、参数和损失连起来

一个神经元先做加权求和 z = w₁x₁ + w₂x₂ + b，再做激活，例如 ReLU(z)=max(0,z)。权重改变输入的影响，偏置移动整体阈值。多层网络组合这些计算，但神经网络不一定很深。

从更简单的价格模型开始：ŷ=wx+b。x是已知输入，y是参考答案，w和b是要学习的参数。若图书页数是x，w类似每页价格，b类似与页数无关的固定费用。真实定价还受品相等因素影响，这只是虚构回归练习。

用平方误差衡量一个样本的偏离：L=(ŷ-y)²；多个样本用平均平方误差 MSE=(1/n)Σ(ŷᵢ-yᵢ)²。损失值回答“当前偏离多少”，梯度回答“各参数改变一点，损失向哪个方向变”。损失低不自动意味着现实任务做得好，还取决于数据、标签和目标是否合适。

已知输入 x ──×w──┐
                 +b → 预测 ŷ → 与 y 比较 → 平方损失 L
参数 w、b ← 更新 ← 各自的偏导 ← 沿原计算关系向后传递

2. 先看单参数，再把偏置放回来

原来的单参数例子仍可手算：ŷ=wx，x=2，y=6，w=0。预测为0，损失36；dL/dw=2(wx-y)x=-24。学习率η=0.05，更新后w=1.2，预测2.4，损失12.96。这个结果正确，但只解释了一条参数路径。

现在使用 ŷ=wx+b，同样取x=2、y=6，初始w=b=0。先把复合计算拆开：e=wx+b-y，L=e²。对w求导时暂时固定b，对b求导时暂时固定w：

变化路径 局部变化率 组合结果
w → e → L ∂e/∂w=x；∂L/∂e=2e ∂L/∂w=2ex=-24
b → e → L ∂e/∂b=1；∂L/∂e=2e ∂L/∂b=2e=-12

η仍为0.05，用同一组旧参数算出的两个梯度同步更新：w新=1.2，b新=0.6。新预测为3，新损失为9。不能先更新w，再拿新w计算b的梯度，却把它说成同一次同步梯度下降；那是另一种更新过程。两个偏导不同，是因为输入x只出现在w这条路径上。

只有一个样本时，许多w、b组合都能满足 2w+b=6，因此损失降为零也不能唯一确定规律。需要更多有代表性的样本检验，而不是把这个例子当成完整模型训练。

3. 多样本更新与学习率：可以自己复现

站内实验用x=[1,2,3]、y=[3,5,7]，即参考关系 y=2x+1。初始w=b=0：三个误差为[-3,-5,-7]，MSE=83/3；∂L/∂w=(2/3)Σeᵢxᵢ=-68/3，∂L/∂b=(2/3)Σeᵢ=-10。

η=0.1时，同步更新为w≈2.266667、b=1。预测约为[3.266667,5.533333,7.8]，MSE≈0.331852。第一步大幅改善不代表后面必然稳定。把η改大，重新从w=b=0开始，比较至少五步的损失；学习率太大可能震荡或发散。

完整操作：先预测两个梯度的正负 → 执行一次更新 → 对照上面的数值 → 记录五步 → 重置，改变学习率，只比较这一个条件。若同时改变初始参数、数据和学习率，就无法知道差异由什么引起。梯度告诉我们当前局部方向，优化器决定怎么走；反向传播负责算梯度，二者不是同一个东西。

4. 链式法则：梯度真的怎样穿过隐藏神经元

用一个隐藏神经元建立最小非线性网络：

x ──×w₁、+b₁──→ z ──ReLU──→ a ──×w₂──→ ŷ ──(ŷ-y)²──→ L
       ↑                        ↑
   第一层参数               输出层参数

取x=2、y=6、w₁=1、b₁=0、w₂=2。前向：z=2，a=2，ŷ=4，L=4。反向从末端开始：

  1. ∂L/∂ŷ=2(ŷ-y)=-4。
  2. ∂ŷ/∂w₂=a=2，所以 ∂L/∂w₂=-4×2=-8。
  3. ∂ŷ/∂a=w₂=2，所以 ∂L/∂a=-4×2=-8。
  4. z>0时ReLU的导数是1，所以 ∂L/∂z=-8×1=-8。
  5. ∂z/∂w₁=x=2，得到 ∂L/∂w₁=-8×2=-16；∂z/∂b₁=1，得到 ∂L/∂b₁=-8。

因此，第一层不是直接拿最终误差乘x；它还要经过输出层w₂和激活函数的局部导数。中间梯度可以复用，这正是反向传播比重复展开所有参数路径更有效的原因。

η=0.01同步更新后，w₁=1.16、b₁=0.08、w₂=2.08；z=2.4，ŷ=4.992，L=1.016064。可以用实验里的参数输入复算，也可以用小扰动检查：[L(w₁+ε)-L(w₁-ε)]/(2ε)应接近-16；ε可取0.000001。数值差分用于小例子核查，计算成本不适合替代大型网络反向传播。

反例：改w₁=-1，其他保持，z=-2，ReLU输出0。虽然L=36，ReLU局部导数为0，w₁、b₁这条路径梯度为0；又因a=0，w₂梯度也为0。有误差不保证每个参数都有非零梯度。z=0处ReLU不可导，实际实现需约定一个值；本实验取0，不能跨这个折点用中心差分判断推导对错。

5. 从标量到矩阵：先核对形状，再做乘法

把两个样本放成行，两个输入特征作为列，隐藏层取三个神经元、输出一列：

对象 形状 含义
X 2×2 两个样本、两个特征
W₁、b₁ 2×3、1×3 第一层权重与偏置
Z=XW₁+b₁；A=ReLU(Z) 2×3 b₁广播到每个样本行
W₂、b₂ 3×1、1×1 输出层参数
Ŷ=AW₂+b₂；Y 2×1 两个预测和参考值

设n=2，G=2(Ŷ-Y)/n，形状2×1。反向：∂L/∂W₂=AᵀG得到3×1；∂L/∂b₂对G按样本行求和得到1×1。再算 D=(GW₂ᵀ)⊙1[Z>0]，形状2×3；∂L/∂W₁=XᵀD得到2×3；∂L/∂b₁对D按行求和得到1×3。梯度应与被更新的参数同形状。

给一组可复核数值：X=[[1,0],[0,1]]，W₁=[[1,0,-1],[0,1,1]]，b₁全0，W₂=[[1],[2],[1]]，b₂=0，Y=[[2],[1]]。前向Z=[[1,0,-1],[0,1,1]]，A=[[1,0,0],[0,1,1]]，Ŷ=[[1],[3]]，MSE=2.5。反向G=[[-1],[2]]；W₂梯度=[[-1],[2],[2]]；b₂梯度=1；D=[[-1,0,0],[0,4,2]]；W₁梯度同D；b₁梯度=[-1,4,2]。零点使用上节的导数约定。

常见错误：把 AᵀG写成AG导致维度不匹配；对偏置保留每个样本梯度而忘记求和；先改W₂再算第一层梯度。先写形状和前向缓存，可以定位这些问题。这里使用行样本约定，换成列样本约定时公式会转置，不要混用。

6. 独立变式：用变化检验是否理解

先独立做，再展开核对。保留输入、预测、梯度、修改记录和解释；计算通过只说明这些固定例子正确。

  • 双参数：把上节三样本目标改为y=2x-1，w=b=0、η=0.1。先算两种偏导，再运行实验中的“目标截距=-1”。解释为什么偏置梯度改变。
  • 隐藏层：x=1、y=3、w₁=2、b₁=-1、w₂=1。画出计算路径，求三个参数梯度。再令b₁=-3，解释为什么大误差仍可能不更新。
  • 矩阵：保持上一节参数，把第一个目标2改为0。只计算新的G和W₂梯度，说明哪些下游计算需要重算。
完成后核对数值与依据

双参数：误差[-1,-3,-5]，MSE=35/3，dw=-44/3，db=-6；更新w=22/15、b=0.6。隐藏层：z=a=ŷ=1，L=4，dw₂=dw₁=db₁=-4；b₁=-3时z=-1，三项梯度为0。矩阵：G=[[1],[2]]，W₂梯度=[[1],[2],[2]]。若结果不同，先定位前向、损失平均、激活导数、矩阵形状哪一步不一致，再修改。

7. 训练变好，实际效果为什么可能变差

训练损失降低只说明对当前训练目标更贴合。比如训练植物图片时，模型可能记住相机、背景而非植物差异。训练损失下降而验证损失上升是可能的过拟合迹象，也要检查标签与数据分布；不能凭一条曲线确定唯一原因。

现象 首先检查 不应立即断言
训练和验证损失都高 标签、特征、目标与优化设置 一定需要更大模型
训练低、验证高 数据代表性、泄漏、过拟合 已学会现实规律
损失震荡 学习率、尺度、异常样本 反向传播必然写错
验证指标突升 数据重复、测试信息混入 已能上线

可以比较正则化、数据增强与按验证表现早停等方法。早停使用验证集，最终测试集应留作独立评价，不能每轮看测试成绩再选参数。常规Dropout训练时随机屏蔽部分激活，评估时关闭随机屏蔽并按所用实现处理尺度；特殊的不确定性估计方法另有约定，不能把例外当普通推理默认行为。
