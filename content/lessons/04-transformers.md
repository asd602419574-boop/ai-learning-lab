# 04｜Transformer：从向量注意力到语言模型

> 学习目标：从Token与向量开始，计算一次Q/K/V注意力并解释输出形状；理解多头、FFN、残差与归一化各解决什么问题；区分上下文使用、参数训练和逐Token生成。
>
> 阅读分层：第1—2节建立直觉，第3—5节为可选计算深入。只需知道向量是一组数，矩阵是多行向量，点积是对应位置相乘再求和；无需先会写训练程序。可靠使用AI的学习者可以先读机制与反例，再按需返回计算。

## 1. 从文字到表示：不是给每个词打一个总分

输入“河岸旁的树叶落到水面，它漂远了”，模型需要结合上下文处理“它”。首先把文字转为Token；一个Token可能是字、词的一部分、标点或特殊符号，并不总等于一个汉字。每个Token查到一组可学习的嵌入数值，再结合位置信息进入网络。

```text
文字 → Token序列 → 每个位置的向量与位置信息
                         ↓
             多层注意力与前馈计算
                         ↓
             每个位置的上下文表示
                         ↓
        输出投影 → 下一个Token概率 → 选择/采样
```

同一个Token在不同上下文里会得到不同的中间表示。注意力的输出通常是一组数，即上下文向量；之后还要经过其他计算，才得到词表上各Token的概率。注意力权重、上下文向量、最终输出概率是三个不同对象。

## 2. 先看加权，再把二维信息放回来

假设当前Token对三个位置的得分为[2,1,0]。softmax把得分转为总和为1的权重，约[0.665241,0.244728,0.090031]。标量值[10,0,-10]的加权和约5.7521，是合法的一维简化，但不能让它成为完整注意力的最终印象。

现在每个位置提供一个**二维Value向量**：v₁=[10,0]，v₂=[0,10]，v₃=[-10,5]。对每个坐标分别使用同一组权重：

- 第一维：0.665241×10+0.244728×0+0.090031×(-10)≈5.7521。
- 第二维：0.665241×0+0.244728×10+0.090031×5≈2.8974。

输出为[5.7521,2.8974]，**不是“这个词的总结分数5.75”**。各坐标不一定有可命名的语言意义；这些数值构成后续网络可利用的表示。若只改Value，权重可以完全不变而输出向量改变。若改Key或Query，权重可能改变；它们控制“从哪里汇总多少信息”。

## 3. 完整示范：Q和K怎样产生得分

实际中，输入表示矩阵X分别乘可学习矩阵WQ、WK、WV，得到Q、K、V。Query表示当前位置参与匹配的查询向量，Key提供匹配向量，Value提供被加权的信息；这是一种功能直觉，不是模型内部有人用自然语言问问题。

先观察一个位置：q=[1,0]，三个Key为[1,0]、[0,1]、[-1,0]，Value仍用上一节二维向量。dₖ=2：

| 步骤 | 运算 | 结果 |
| --- | --- | --- |
| 点积 | q分别点乘三个Key | [1,0,-1] |
| 缩放 | 除以√2 | [0.707107,0,-0.707107] |
| softmax | exp后除以总和 | 约[0.575975,0.283995,0.140029] |
| 汇总V | 对三个Value向量加权 | 约[4.3595,3.5401] |

为了避免指数溢出，实现softmax时可以先从每个得分减去该行最大值，这不改变归一化结果。缩放因子与Key/Query的维度有关；高维点积若尺度过大，softmax可能过于尖锐。权重总和为1并不保证选中的证据正确，更不构成事实或因果证明。

完整序列同时计算时，设3个Token、输入维度4、dₖ=2、dᵥ=2：X为3×4，WQ/WK/WV各为4×2，Q/K/V各为3×2；`QKᵀ`得到3×3，每行代表一个查询位置对三个位置的得分。逐行softmax后仍是3×3，再乘V得到**3×2**：每个位置一个二维上下文向量。常见公式为：

`Attention(Q,K,V)=softmax(QKᵀ/√dₖ)V`

若Value维度改为5，输出就是3×5；Query和Key维度必须能做点积，Value不必与它们同维。下一步通常还需输出投影，不能把注意力输出维度与词表大小混淆。

## 4. 为什么一个Transformer块还需要其他部分

只做加权平均，表达能力和深层训练都有限。原始Transformer把几个部件组合起来，各自解决不同问题：

| 部件 | 怎样计算/作用 | 不能替代什么 |
| --- | --- | --- |
| 多头注意力 | 用不同WQ/WK/WV投影并行汇总，拼接各头输出后乘WO | 不是把同一结果复制多遍；各头不保证有固定的“语法/语义”标签 |
| FFN前馈网络 | 每个位置独立做 `W₂·激活(W₁·h+b₁)+b₂`（此行采用列向量写法） | 在位置内部做非线性特征变换，不直接承担跨位置信息汇总 |
| 残差连接 | 将子层输入加回输出，例如x+F(x) | 保留信息与梯度通路；不等于跳过训练或自动防止过拟合 |
| 层归一化 | 对一个位置的特征维计算均值/方差，再做可学习缩放和平移 | 调整数值尺度；不是把一批样本混在一起，也不是softmax概率化 |

多头小例：头1输出[1,0]、头2输出[0,2]，拼接是[1,0,0,2]；若WO形状4×4，再投影回4维以便残差相加。拼接不是逐元素平均。一个头已能运行注意力，但原始模型通过多个投影子空间增强表征，并非“没有多头就不能计算注意力”。

FFN小例：某位置h=[1,-1]，选一个隐藏映射产生[1,-1,0]，ReLU后[1,0,0]，再映回[2,0]。这是对本位置的特征组合；其他位置也过同一组FFN参数，但不同输入产生不同输出。实际模型的激活/结构可能不同，本例只展示非线性与维度来回映射。

LayerNorm数值例：x=[1,3]，均值2，特征方差1；忽略很小的ε，标准化约为[-1,1]，再乘可学习γ、加β。标准化后仍是一组有正有负的特征，不是总和为1的权重。

原始编码器块可画成：

```text
X → 多头注意力 → 与X相加 → LayerNorm → H
H → FFN        → 与H相加 → LayerNorm → 下一层
```

这是原论文的Post-LN形式；其他实现可能把归一化放在子层之前，或用RMSNorm等变体。应理解部件的角色与形状约束，而不是背一种顺序当作全部语言模型的唯一结构。

## 5. 位置、因果遮罩与逐Token生成

“猫追狗”和“狗追猫”的词集合相同，但关系不同。没有位置信息时，单靠无位置信息的自注意力不能表达所需的顺序关系。位置编码、相对位置或旋转位置编码等方法让模型利用顺序；它们的实现不同，本课不把它们混成同一种算法。

生成式模型还要阻止当前位置偷看未来答案。因果遮罩在softmax前把禁止位置设为不可参与的得分，归一化后其权重为0。仅降低一点得分不能保证不泄漏。编码任务可以允许双向查看上下文，不能给所有Transformer一律套相同遮罩。

得到最后位置的表示后，通过输出投影产生词表得分，再得到下一Token分布。温度影响分布尖锐程度，Top-p限制候选范围；它们不是“知识正确率开关”。选择一个Token后，把它接回序列继续计算，直到结束条件或长度限制。上下文窗口大也不保证每处信息都能可靠使用。

## 6. 训练、微调、上下文学习与推理

| 情境 | 信息如何进入 | 普通情况下是否更新权重 |
| --- | --- | --- |
| 预训练 | 数据与损失驱动优化 | 是 |
| 指令微调 | 指令/回答样本驱动优化 | 是 |
| 提示里给三个示范，再回答第四题 | 使用本次输入中的示范，即上下文学习 | 否 |
| RAG把检索片段放入输入 | 使用外部上下文 | 不自动更新基础模型权重 |
| 普通生成 | 使用现有参数计算 | 否 |

一个模型可以在同一次对话里利用新规则，不代表永久学入参数；新会话不提供这些规则时，结果可能不同。平台保存对话、应用保存记忆、训练更新模型参数也是不同层面的持久化。LoRA、量化与真实工具协议不在本轮实现；它们仍需各自的原理、操作与验证专题。

## 7. 动手与独立迁移：分别改变匹配和内容

站内注意力实验接受JSON向量与矩阵，每次运行都真实计算点积、缩放、softmax和向量加权，不调用模型服务。先照第3节输入，核对四个中间结果；再只把V第三行改为[-10,20]，预测权重是否改变、输出哪一维改变。随后只改q=[0,1]，观察Key匹配如何改变。保存运行证据时写清输入、维度、结果及解释，不把数值检查当成语义理解认证。

独立变式：q=[1,0]，K=[[0,1],[0,2]]，V=[[2,4],[6,8]]。先写出缩放得分、权重和上下文向量，再在实验中验证。若把第二行V改为[10,8]，只算新的输出；解释为什么“两个Key不同”仍能得到相同权重。

<details><summary>独立作答后核对</summary><p>两个点积都是0，缩放后仍为0，所以权重各0.5，输出[4,6]。修改V后输出[6,6]，权重仍相同；q只读取Key第一维，而两行第一维都为0。输出不是某个Token的正确概率。若把K写成两行一列，q的两维无法与一维Key点乘，应先修维度，而非靠试错改变数字。</p></details>

外部应用变式：选择一份可核对的公开通知，要求模型提取事实并逐项引用。分别不给材料、给正确材料、给缺少一个条件的材料，记录遗漏和无依据补充。这个实验测试具体输入条件下的行为，不能证明模型内部哪一头代表某个事实，也不能凭注意力权重证明因果关系。

**延伸阅读**：[Attention Is All You Need 原始论文](https://arxiv.org/html/1706.03762v7)第3节（注意力、多头、FFN、位置与残差归一化）、[D2L 注意力机制](https://d2l.ai/chapter_attention-mechanisms-and-transformers/index.html)。本课数值、图解和变式为原创教学材料；小维度计算不等同于运行完整语言模型，也未验证真实学习效果。
