## 当前版本运行与体验

在仓库根目录运行：

```powershell
python -m http.server 8876 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8876/#home>，未开始学习时点击“了解课程安排，开始基础学习”，进入[基础学习说明](http://127.0.0.1:8876/#pathways)。先了解四节入门资料、六章系统基础、专题教材之间的关系，以及完整16天 / 32单元培训安排，再点击“开始基础资料学习”。16天是集中安排参考，部分专题仍为大纲与任务说明，部分实操涉及外部工具，不表示已具备16天完整独立自学课。

每节入门课默认先展示背景、原理、案例与完整示范等七段正文；阅读后显式进入“预测 → 尝试 → 观察 → 解释 → 重试 → 迁移”练习。练习入口使用 `#lesson?id=课程ID&view=practice`；已有练习记录可继续上次练习。保存后到“个人成果”回看、导出或备份。可以刷新续学；没有账号或云同步，记录限当前浏览器与域名。阅读不改变既有步骤号或学习存储结构。本次修正未启动 P4，未部署；本地验证见核心开发计划，提交与推送版本以实际 Git 记录为准。

四课使用原创虚构材料、固定模拟回答和明确字段规则，无需密钥、付费或实时模型调用。自由解释与自评不会自动转换为知识掌握分数。旧教材、基础题、培训及项目仍可从资源架或学习路线进入。

当前页面需要保留 `learning/`、`content/`、`projects/`、`training/`、`feedback/` 和 `desktop.css` 等实际静态依赖，不能只复制 `index.html`。修改基础数据后执行 `node scripts/build_ui.js` 重新生成入口，基础题源在 `content/foundations.js`。课程阅读使用 HTTP 服务。

从基础学习说明按顺序阅读四课，也可直接访问以下资料入口：

每课独立保存。只有保存了字段规则通过的迁移作品，并补齐解释、复盘和三项自评，才记“本课任务完成”；选择通过不会自动等于知识掌握。原课继续沿用 `ai_lab_learning_v2`，三节新课使用 `ai_lab_pathway_v1`，旧备份仍可恢复。

## 交付内容

- `index.html`：静态单文件网站，原生 HTML/CSS/JS，无外部依赖、不需要数据库、构建或 API key。
- `DEPLOY_AGENT_TASK.md`：交给腾讯云服务器智能体 / Codex 的最小部署与验收指令。

## 在 V1.1.1 上的增量升级

1. 学习首页：今日推荐、已达标章节、闯关进度、复习卡数量。
2. 主动回忆：先看术语尝试回忆，再翻卡核对，按「想不起来／比较吃力／基本记得／非常熟悉」自评。
3. 简化间隔复习：自评之后安排到期时间，建立到期复习队列。首次间隔为 10 分钟、1 天、3 天、7 天；后续根据既往间隔和自评向后推移。**这不是 FSRS，也未承诺最优记忆效果**。尚未评级的新卡不会自动算成到期。
4. 互动实验：8 条虚构设备数据的故障阈值实验（精确率、召回率、误报、漏检）；1000 条工单划分实验（训练/验证/测试占比、数据泄漏警示）。**不实际训练 AI 模型，不承诺真实模型效果**。
5. 六章情境任务：每章 2 个决策节点，选择—反馈—重试—完成；记录完成状态。
6. 保留六章、18 个深度专题、31 张基础概念卡、120 道原题及错题复习。

## 已有数据兼容

沿用浏览器 localStorage 键：`ai_foundations_learning_v1`。

保留原 `mastered`、`known`、`best`、`bestPct`、`questionStats` 字段；新增 `reviewCards` 和 `missions`。全部 120 道题 ID 与 V1.1.1 一致。已有「已记住」标记不会自动转换成新的“到期复习”卡，需用户主动核对一次并给出自评。

学习数据只保存在**同一个浏览器、同一个域名的同一存储分区**。换设备、清理浏览器存储或更换域名会影响可用性，不提供跨设备同步。

## 本地运行

双击 `index.html` 可以查看。浏览器若对 `file://` 限制本地存储，请通过已有 Nginx 静态站点或本地 HTTP 服务打开。

## 验证范围

在隔离 Chromium 环境通过 `page.set_content()` 运行 DOM 与交互测试。因执行环境不允许直接 `file://` 或 localhost 页面导航，测试使用 in-memory localStorage 模拟存储接口，**不等于已验证线上真实域名的数据持久化行为**。

已验证：
- 6 章 / 18 专题 / 31 概念卡 / 120 原题的数量，120 道原题 ID 与 V1.1.1 完全一致；
- 章节切换、主动回忆、复习评级、到期队列、两项实验、场景闯关、原章节测验计分；
- 旧版达标、错题、翻卡数据的读取兼容；
- 390px 手机布局无水平溢出及基本互动。

## 开源复用决策

延续现有无依赖单文件架构；评估 `open-spaced-repetition/ts-fsrs`（https://github.com/open-spaced-repetition/ts-fsrs）后暂不集成，因为现阶段采用简单、可解释的复习规则足以建立初版闭环。后续只有收集到足够复习历史、确实需要优化调度时才考虑适配成熟实现。

## 重要说明

发布前请先对比线上当前 `index.html` 和本次交付的 V1.1.1 基线，不要在有其他新改动时盲目覆盖。若线上并非 V1.1.1，先合并差异、确认 V1.1.1 已修正的教学内容未丢失，然后部署。唯一必要的生产验收是核心学习链路和旧进度能否正常使用。


## 源码仓库与部署原则

- **权威可部署入口**：仓库根目录 `index.html`（单文件包含 HTML、CSS、JS，无需构建）。
- **验证脚本**：`tests/test_v12.py`，使用 Python Playwright 与本机 Chromium；测试使用模拟的 localStorage，不代表线上持久化验证。
- **部署说明**：`docs/DEPLOY_AGENT_TASK.md`。只替换独立学习站点的 `index.html`，先备份并比较线上差异。
- **页面预览**：`previews/`。这些不是运行时必需文件。
- **敏感数据**：不提交服务器私钥、SSH 配置、DNS 凭据，也不将学生浏览器中的 localStorage 数据上传仓库。
- **版本**：V1.2.0，首次导入；不假定线上已部署此版本。

> 当前保留原生单文件应用结构，后续新增功能建议先检查并复用现有 JS 函数和存储键，不要为了构建工具重写已经稳定的应用。
