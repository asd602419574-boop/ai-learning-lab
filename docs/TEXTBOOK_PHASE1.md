# V1.6 系统教材一期（2026-10-20）

## 范围与定位

这次交付的是**真实文章与两项可重复计算的学习实验**，而非新增题量。以当前 GitHub `main` 的 V1.4/V1.5 版本为基线，保留原六章、144 道基础题、16 天培训与 64 道专项题、原有互动课和反馈服务，不改变任何旧成绩存储键。

- `content/lessons/`：8 篇独立的原创 Markdown 教材原文。
- `content/rendered/`：8 篇构建生成的静态 HTML 片段，站点可直接读取。
- `content/manifest.json`：标题、分组、建议时长、前置知识、理解检查题、文件路径。
- `content/reader.js` / `content/reader.css`：教材阅读界面、目录、浏览器本地进度、16 道题的即时反馈、两项计算实验。
- `index.html`：只新增一个教材入口、两条资源引用和必要分发逻辑。其他功能模块原样保留。

## 8 篇文章

1. 从业务问题到 AI 系统；2. 机器学习与正确评估；3. 神经网络与梯度下降；4. Transformer 与语言模型；5. Prompt 与可靠输出；6. RAG：从检索到可信引用；7. Agent：工具、权限与状态；8. 数据标注与 AI 项目交付。

每篇按“问题 → 原理 → 带数字/流程例子 → 失败情形 → 课后任务 → 回忆”组织。每篇可阅读十多分钟，约 2,000–2,600 个源文档字符（含标记和代码示例）；后续章节深化不受固定字数限制。

## 可运行实验的边界

1. 梯度下降：样本 `x=[1,2,3], y=[2,4,6]`，模型 `ŷ=wx`，使用平均平方误差的真实导数，每次点击执行一次梯度更新。能改变学习率，观察收敛/发散。
2. RAG **检索层**：中文双字词项 + 英文词项构成简化关键词匹配，查询词、Top-K、匹配得分和引用都来自实时计算。没有向量索引、联网搜索或调用语言模型。不能将其宣传为完整的语义 RAG。

## 学习状态

`ai_lab_textbook_v1` 仅保存新教材阅读和自测结果，不触碰旧的 `ai_foundations_learning_v1` 或 `ai_training_16day_v1`。标记“完成阅读”仅是阅读任务确认，不代表知识已达标。若浏览器阻止 localStorage，告知用户无法保存。

## 构建方式与依赖

仅**作者构建环节**使用 Python `mistune` v3（项目 BSD-3-Clause 许可），生成已转义 HTML 片段。静态网站访问时无 Markdown 渲染依赖、无需服务器后端、无需联网 CDN。

```bash
python -m pip install 'mistune>=3,<4'
python scripts/build_textbook.py
node tests/test_textbook.cjs
```

## 部署交接

在合并功能分支、校验源码和必要交互后，将仓库的 `index.html` 及**整个 `content/`** 部署到 `learn.liftime.xyz` 的同一静态站点根目录；如果只替换 `index.html`，教材加载会 404。现有 `training/`、`feedback/` 和 `server/` 原状保留。先备份当前入口，部署前确认线上未提交更改，验证教材首页、任意一篇、动态实验、返回旧章节、页面刷新进度及移动端。无 P0/P1 即可结束，不扩大测试范围。
