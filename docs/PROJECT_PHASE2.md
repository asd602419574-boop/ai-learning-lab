# V1.7 项目式学习第二阶段交付说明

## 目标

承接 PR #3 的 8 篇系统教材，从单点互动实验过渡到四个有明确输入、计算过程、验证指标、错误路径与可导出成果的本地完整项目。这里的“真实项目”特指运行真实小型算法与可观察状态变更，并非连接生产数据、外部 LLM 或真实业务 API。代码原创，纯静态 HTML/JS，可脱机运行除教材首屏静态资源加载之外的项目互动。

## 四个项目

1. **数据标注与质量评估**：12 条公开领域模拟文本、3 类标签、规范提示、用户独立标注、参考标签对照、3×3 混淆矩阵、每类精确率/召回率/F1、宏 F1、相对参考的 Cohen κ、CSV 导出。注意预置参考不等于真实双人盲标。
2. **朴素贝叶斯文本分类器**：18 条独立训练、8 条留出测试样本、中文双字词项和英文单词、实际计数与对数概率、Laplace α 调节、留出集结果、独立文本推理与 JSON 导出。样本太小且人工构造，不可推广到真实垃圾邮件过滤效果。
3. **可追溯检索评估**：6 份教学资料，字符分块与重叠、平滑逆文档频率计算、词频加权、Top-K 检索与证据摘录、6 道测试问题 Recall@K、MRR、最多 3 份自定义文档。非向量检索，非完整 BM25，非生成式 RAG；没有事实编造能力的“回答生成”。
4. **受控日历 Agent 工具练习**：只在浏览器状态操作沙箱日历。先读，再检查冲突，再提出具体方案，再由用户明确授权，才允许新增事件；计划变化撤销旧授权，支持审计轨迹和新增事件回滚。它是确定性受控执行器，**不具备自主模型规划，也不会调用真实日历 API**。

四个项目各附有教学讲解（概念、公式/策略、步骤、失败情形、验收清单、进阶任务），并与基础教材一起在同一学习平台呈现。

## 源码清单

- `projects/logic.js`：纯计算、静态教学资料、可由 Node 独立验证。
- `projects/guides.js`：每项独立原创项目教学说明和验收要求。
- `projects/app.js`：项目目录、任务 UI、事件处理、指标解释、CSV/JSON 导出与学习状态。
- `projects/projects.css`：隔离的响应式样式。
- `index.html`：仅新增入口、静态资源引用、项目路由与首页快捷入口。
- `tests/test_project_logic.cjs`：无第三方依赖的算法与安全门槛检查。
- `tests/test_project_browser.py`：Playwright Chromium 交互、导出、刷新、旧数据兼容和手机测试。

旧版 `content/`、`training/`、`feedback/`、`server/` 不修改。新版只新增 `ai_lab_projects_v1` localStorage 键，兼容原有保存方式。清除浏览器数据会丢失进度，所以提供本地导出；不包含跨设备同步。

## 项目验收与评分

“项目达标”是**最低自动检查**而非专业能力认证：标注需全部完成并核对参考；ML 需训练并输入新文本；RAG 需检索且运行标准评测；Agent 需得到授权后成功写入至少一条本地沙箱事件。进阶评分仍需学员按照项目讲解中的验收清单，解释公式、提交复盘与独立设计失败案例。按下按钮不等于真正掌握知识。

## 验证方法

```bash
node tests/test_project_logic.cjs
python tests/test_project_browser.py
```

前端脚本在源代码层均通过 `node --check`。所有真实对外功能仍需部署前由 Codex 做最小必要检查，尤其教材资源的 HTTP 加载、反馈模块和用户旧数据。注意测试中原有后端未被实际启动。

## 部署策略

**本阶段只提交到 GitHub，不部署。** 因 PR #3 尚未合并，功能分支以 PR #3 的准确 head SHA 为起点，PR 以 `feat/textbook-core-v1.6` 为基础分支。Codex 应先合并 PR #3，再核对并将本 PR 改为合并至 `main`；不要只复制 `index.html`，须连同 `content/` 和 `projects/` 目录一起部署，保留 `training/`、`feedback/`、`server/` 原有功能。备份线上文件并按增量验证后再升级网站。

## 本阶段未实现的能力

生产级数据标注平台、真实多标注员协同、LLM API/向量嵌入、网络工具调用、外部日历集成、账户进度同步、服务端安全认证、GPU 大模型训练。这些不能根据本次教学练习宣称已经实现。
