## 1. 设计哲学与核心原则

方案 A（**Editorial Stream / 呼吸感编辑流**）旨在摆脱传统教学管理后台（LMS）和旧版多层“套娃式”灰框的紧凑压迫感，采用**面向现代消费级产品与高品质文档编辑工具**（如 Linear、Vercel、Claude Artifacts、Medium）的视觉语言。

* **大留白与层次克制**：主容器最大宽度收敛至 `1140px`，板块间距拉大至 `56px` 以上。拒绝任何无意义的内嵌边框，依靠微弱的边框线条（`#e2e8f0`）、清爽的微阴影（`shadow-sm` 至 `shadow-lg`）与字号权重定义容器层级。
* **去除内部开发代号**：产品界面面向零基础初学者与个人维护者，界面中彻底移除所有需求编号（如 `R01`, `R11`）与密集内部标签，回归“学习者正在推进的具体任务”。
* **单主线聚焦，拒绝信息轰炸**：首屏通过 7:5 黄金分割双栏突出“继续上次实作”与“个人成长快照”；将第二屏原本拥挤的四条路线合并为**分段标签切换器（Segmented Tabs）**，每次仅高留白展示 3 张核心课程卡片。

## 2. 视觉 Token（方案 A · 现代呼吸亮色基底）

| 语义分类 | 属性名称 | Token 数值 / 表现 | 设计意图 |
|---|---|---|---|
| **背景色系** | 页面底色 (`--bg-page`) | `#f8fafc` (极浅灰蓝) | 降低强白光造成的视觉疲劳，提升高级感 |
| | 表面卡片 (`--bg-surface`) | `#ffffff` (纯白) | 确保卡片与底色形成温和、清晰的物理断层 |
| | 柔和填充 (`--bg-subtle`) | `#f1f5f9` | 用于非焦点胶囊、标签及次要容器背景 |
| **排版字号** | 标题字号 (`welcome-title`) | `28px` / 行高 `1.25` | 兼具视觉冲击力与呼吸感 |
| | 正文字号 (`font-size`) | `15px` / 行高 `1.65` | 保证长时间阅读时的极佳舒适度 |
| **色彩点缀** | 品牌主色 (`--accent`) | `#4f46e5` (Indigo) | 引导核心交互与主操作按钮 |
| | 成功状态 (`--success`) | `#059669` (Emerald) | 用于“自动检查通过”、“已完成”状态 |
| | 警告/提示 (`--warning`) | `#d97706` (Amber) | 用于“待复检”、“草稿未同步”提醒 |
| **阴影规格** | 默认卡片 (`--shadow-sm`) | `0 1px 2px rgba(15,23,42,0.03)` | 极轻微托起 |
| | 焦点悬浮 (`--shadow-md`) | `0 12px 32px -8px rgba(15,23,42,0.06)` | 悬停时的空气浮动感 |

## 3. 核心板块结构深度展开

### 3.1 首屏：欢迎语与 7:5 双栏主焦点
* **左侧主卡（英雄焦点卡）**：
  * **标题**：“继续你的 AI 探索之旅”
  * **当前焦点任务**：自动加载上次未完成的 P1 首发样板课《可靠使用 AI：识别幻觉与引用核对》。
  * **6 步清爽时间轴**：将旧版拥挤的方格演进为清爽的单行节点流（`✓ 1. 先预测` → `✓ 2. 动手尝试` → `✓ 3. 观察差异` → `● 4. 解释原因` → `5. 重试` → `6. 迁移`）。
  * **行动按钮**：一键直达《单课实作工作台》。
* **右侧副卡（个人成长与快照）**：
  * 提供 3 格简洁指标（已归档作品数、知识练习达标数、最近独立完成提示依赖度）。
  * 实时摘要最新成果（如《活动通知核对清单 v2》）。

### 3.2 第二屏：分段标签切换的体系化路线
拒绝将初学者淹没在数十个网格中。通过顶部 **Segmented Tabs** 切换查看：
1. **1. 共同基础**：Module 01（P1 样板课）➔ Module 02（原理直觉）➔ Module 03（质量判断）。
2. **2. AI 日常应用**：多源证据比较 ➔ 结构化清洗 ➔ 外部产物本地摘要自评。
3. **3. AI 项目构建**：小系统需求切片 ➔ 检索阈值调优实验 ➔ 空检索降级处理。
4. **4. 架构与工程进阶**：模块数据流图与状态契约 ➔ 异常恢复回归验证 ➔ 流程复盘交付。

### 3.3 第三屏：四列自主学习资源架
以 4 张无边框、悬浮交互的扁平卡片平铺呈现既有资产：
* **📖 12 篇深度教材阅读器**（含机制、贯穿例子与延伸阅读）
* **🧠 六章基础 & 144 道基础题库**（含主动回忆、错题本与变式复练）
* **🧪 4 个浏览器交互实验**（纯前端本地算法，零云端 API 依赖）
* **🗂️ 16 天 / 32 单元专题库**（实事求是标注 P3 待扩充状态）
