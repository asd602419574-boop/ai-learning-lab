# 电流探索：首次初学者独立试学

状态：UI/UX 体验已优化完成，试学任务单已准备；尚未取得真人初学者试学证据。自动化验收通过不代表教学效果已验证。

## 一、运行环境与试学安排

从仓库启动静态服务：`python3 -m http.server 8876 --bind 127.0.0.1`。
在浏览器打开 <http://127.0.0.1:8876/#home>，选择物理学科，再进入电流课程。
若已有服务占用 8876 端口，先核实服务目录，不停止其他服务；更换端口会产生不同的本地存储源，历史记录不会跨端口自动迁移。

请一名初次接触电学的学习者独立操作。时长由学习者自行把握，不设限时、不评分、不设外部排名或能力等级认证。
观察者全程保持旁观记录困难，不代替学习者填写或操作；若学习者遭遇阻碍必须提示，详实记录提示的具体内容与时机。

## 二、试学核心操作流程

1. **首页与导引：** 从首页找到“物理”入口；先完整阅读背景知识、微观机制、物理量定义与完整示范。用自己的话向观察者解释电压、电阻、电流的单位与含义，以及理想模拟计算值与真实仪器测量的区别。
2. **任务 1（固定电阻，改变电压）：** 显式点击“已读原理与示范，开始实验”进入工作区。先在任务 1 中填写预测与理由，点击“锁定预测，开始本轮”。保持单电阻 10 Ω、开关闭合，在控制台分别设置 3.0 V 与 6.0 V 并点击“记录本轮条件与读数”。核对实时核验清单是否变绿，写下对比解释与复盘。
3. **任务 2（固定电压，改变电阻）：** 切换到任务 2，保持电压 6.0 V，分别记录 10 Ω 与 20 Ω 的模拟值。若观察与预测不符，检查是否误动电压或未闭合开关，记录修正说明后开始新一轮并重试，确认历史轮次完好保留。
4. **任务 3（独立迁移：多一条支路）：** 切换到任务 3，6.0 V 电源连接 10 Ω 与 20 Ω 两段电阻。先预测并联的总电流与两支路电流，再在控制台切换“并联”并记录。解释为什么不能把并联电阻直接相加，以及支路电流与总电流的关系。
5. **提交与快照：** 检查任务证据核验状态，点击“提交并保存当前版本”。刷新网页，确认草稿、观测数据、对比解释和提交版本快照均在。导出本实验 JSON 文件；尝试修改一段解释文字，观察提交状态变化；选择刚刚导出的 JSON，核实“先预览、确认后再覆盖本课”的恢复流程。
6. **边界与探究操作：** 任选“零电压”、“反转电源极性”、“断路”或“改变电阻丝截面积”中的两个操作，说明它们对模型计算读数与微观动画各产生什么影响。可随时回看原理示范。

## 三、初学者独立使用观察维度表

记录以下真实行为证据，不采集任何无关个人身份信息：

| 观察维度 | 重点核实问题 | 现场观察与初学者反馈记录 |
|---|---|---|
| **起点与指引** | 是否知道从何处开始？是否理解“先读资料、理解示范，再显式进入实验”的时序？ | |
| **物理量与单位** | 是否混淆电压（推力/电势差）、电阻（阻碍）、电流（流动率）的概念？是否看懂公式 I = U / R？ | |
| **模型与实测认知** | 是否理解模拟读数来自理想恒温欧姆模型精确计算，不等于真实实验室仪表的内阻和测量误差？ | |
| **预测与调参时序** | 是否知道先在思考区填写预测并锁定，再调节参数；还是直接盲目拖动滑块？ | |
| **证据清单与差异** | 是否能看懂实时核验清单提示？是否能看出改变电压时电流成正比翻倍，并对比解释差异？ | |
| **任务切换与流程** | 在任务1、任务2、任务3之间切换时，是否理解各任务的变量控制要求？是否能分清并联支路与总电流？ | |
| **提交状态与版本** | 是否理解何时三项证据齐全可以提交？修改内容后是否注意到提交状态恢复为待提交？历史版本是否清晰？ | |
| **保存与恢复体验** | 是否看懂自动保存提示、独立 JSON 导出、以及文件导入时的“先预览、确认后再覆盖”？ | |
| **视口与操控** | 桌面大屏（1080p/2K/4K）或手机窄屏（如 390px）下，滑块、按钮和图表是否容易点击操作？是否有局部遮挡？ | |

## 四、问题分级与处理原则

1. **P0 / P1（阻断级）：** 若存在阻断初学者独立操作、公式计算错误、读数与参数不符、或造成数据丢失的问题，立即修复并回归验证。
2. **教学与理解困难：** 初学者对专业物理术语（如“导纳”、“晶格离子漂移”）或复杂串并联拓扑的真实困惑，如实记录在观察单中，作为后续版本教学脚本和提示微调的依据；不擅自据此推断群体学习效果。
3. **范围边界：** 本次试学与优化聚焦于 V3.0-A 电流探索课程本身的初学者体验，不启动 V3.0-B，不重构跨学科备份架构。
