# 部署任务：learn.liftime.xyz 升级 V1.2

> **历史归档，不作为当前发布指令。** 本文只对应早期 V1.2 单文件交付，以下“仅替换 index.html”的步骤不适用于当前版本。当前页面依赖多目录静态资源，请使用[当前部署说明](DEPLOY_CURRENT.md)。历史授权不等于现在的生产部署授权，本文哈希也不表示当前线上版本。

## 授权范围

仅更新已存在的 `learn.liftime.xyz` 静态学习网站代码。不修改其他域名、反向代理、证书管理、数据库、Ops/Gateway 或安全组配置。

## 输入

部署包内 `index.html` 即可运行的 V1.2 HTML。它基于已交付的 V1.1.1 创建。

交付参考 SHA256：
- V1.1.1 基线 `2d9068872ce198dcb6711efae0675093436fd1d6bb2c9e5945e020c6820b7543`
- V1.2 交付文件 `682dad6c31a8b520759fce8a5da30b335b6043bcae45935e2ee8d6bd4fadbf5b`

## 执行步骤

1. 通过现有站点配置确定 `learn.liftime.xyz` 的实际生效静态根目录及 `index.html`，不要猜测目录，也不要操作其他站点。
2. 备份线上当前 `index.html` 到服务器同目录之外的带时间戳备份路径，记录哈希值。
3. 检查线上基线与本任务输入的差异：如果当前站点仍为 V1.1 或包含 V1.1.1 之外的新改动，先做最小合并，避免覆盖任何已上线教学修订或新增功能。若无法安全判断，**停止覆盖并报告差异**。
4. 原位仅替换学站的 `index.html`；保留现有 Web 服务器与 HTTPS 配置。静态文件无需额外进程或服务重启（除非当前环境特殊）。
5. 验收 `https://learn.liftime.xyz` 正常加载 V1.2：六章、31 张概念卡、18 专题、120 题；主动回忆评级后刷新仍保存；复习队列显示到期卡片；阈值拖动更新精确率与召回率；数据划分实验可切换泄漏提示；六章闯关中的一章完整通关；旧版章节达标和错题记录保留。
6. 确认原网站 `portfolio.liftime.xyz`、`tacp.liftime.xyz` 等原有站点可访问，报告部署结果、时间、哈希与有无回滚。

## 停止与回滚

如静态网页加载失败、120 道原题丢失、已有学习记录异常或其他站点受影响，停止并用本次备份恢复原文件。不要擅自清除浏览器 localStorage。线上数据保存在用户自己的浏览器，服务器端无法代表用户验证完整的旧记录恢复，需由用户在原浏览器确认。
