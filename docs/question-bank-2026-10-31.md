# 题库质量修订（2026-10-31）

## 背景

线上 V3.0-A（提交 `7641dda`）的题目存在三类会削弱学习价值的问题：

1. **答案位置可预测**：专题教材 45 道题中有 40 道正确答案在 B；基础题答案位置从 31.9% 递减到 16.0%。
2. **选项长度泄露答案**：正确答案明显长于所有干扰项（≥4 字）的比例在基础题、教材题、培训题分别为 31.9%、46.7%、60.9%，学习者可以靠“挑最长”蒙对。
3. **干扰项凑数**：不少错误选项是“浏览器缓存”“按钮圆角”“服务器风扇转速”等与本课无关的内容，看起来像机器批量生成。

本修订只改选择题的选项、答案位置与解析；题干、题目 ID、章节归属与题量不变，因此 `ai_foundations_learning_v1` 等存储键中的逐题记录仍能归位。

## 修订范围

| 题库 | 题量 | 选题来源 | 改动 |
|---|---:|---|---|
| 基础六章 | 144 | `content/foundations.js` | 全部选项与解析重写 |
| 专题教材 | 45 | `content/lesson-quizzes.json` | 全部选项与解析重写 |
| 16 天培训 | 64 | `training/training-data.js` | 全部选项与解析重写 |

题目 ID 规则没有变化：基础题为 `c{章}-q{序}`，培训题为 `tr-d{天}-q{序}`，教材题按课内顺序计。

## 修订前后指标

| 指标 | 基础 144 | 教材 45 | 培训 64 |
|---|---:|---:|---:|
| 答案位置（修订前） | 31.9 / 28.5 / 23.6 / 16.0% | 8.9 / **88.9** / 2.2 / 0% | 26.6 / 28.1 / 21.9 / 23.4% |
| 答案位置（修订后） | 25 / 25 / 25 / 25% | 24.4 / 26.7 / 24.4 / 24.4% | 25 / 25 / 25 / 25% |
| 正确答案比所有干扰项长 ≥4 字（修订前） | 31.9% | 46.7% | 60.9% |
| 同上（修订后） | 0% | 0% | 0% |
| 解析平均字数（修订前 → 后） | 24.7 → 50.2 | 29.6 → 51.3 | 17.8 → 43.2 |

“正确答案是最长选项”的统计仍约为 73.6% / 66.7% / 75.0%，但所有题的强线索均为 0：正确答案最多只比最长的干扰项多 3 个字符，且大量为并列最长。选项都在单行内显示，1–3 字的差别不构成人类学习者可用的位置线索；门禁只拦截 ≥4 字的明显差距。

## 出题规则

- 四个选项，同一题干只考一个判断点。
- 三个干扰项来自同领域的常见误解，不使用与本课无关的技术名词凑数。
- 正确答案不系统性地更长；若必须写长，至少让一个干扰项同样长。
- 答案位置在每章、每课、每天内分散，整体接近 25%。
- 解析至少两句话：第一句说明正确理由，第二句点出最容易误选的选项错在哪里。
- 题干、题目 ID、选项数量与在题库中的位置保持不变。

## 实现变化

- `content/lesson-quizzes.json` 成为 13 篇教材题的唯一来源；`scripts/build_textbook.py` 只保留课程元数据，再按 `id` 合并题目。`content/extra-lessons.json` 不再保存题目。
- `scripts/check_questions.cjs` 校验题量、答案位置、长度线索、重复选项/题干、解析长度，已接入 `.github/workflows/verify.yml`。
- `tests/fixtures/foundations-questions-v2.json` 是新基线；`question-baseline.cjs` 断言 v2。v1 文件保留作历史出处。
- `tests/test_depth_browser.cjs` 不再硬编码正确选项位置，改为读取 `content/manifest.json`。

## 兼容与限制

- 保留题量与 ID，但题干之外的措辞、选项次序和正确答案位置已经改变；历史错题记录仍指向同一个 ID，但该 ID 对应的题面内容已更新。
- 未验证真实学员的长期学习效果；本次只验证了题目结构、作答流程和记录归位。
- 未自动提交、推送或部署。
